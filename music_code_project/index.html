Music X Code

is a series of performances using Strudel(coding enviroment browser for live music) and Hydra(live code-able video synth). Each performance incorporates voice notes contributed by the current audience, integrating their sounds into the music. The concept of the project was based on my discomfort of using Strudel software as I have never made music before, so I was hyperfixated on the perfect sound which would often stop me from learning. As a result I thought to curate a project where the audience can influence the music by sending voice notes, to play on the idea/ remind me I have no control over the situation and push myself to use the voice notes sent from audience members on the spot. The performances were in collaborative project under the duo name of "Shalisha"

Process

I developed a Python program that automates the collection and conversion of voice messages from my personal iMessage database, so it can used in Strudel. I first wrote and tested an SQL query in DB Browser for SQLite to retrieve a specific number of the most recent received voice messages, ordered by date. After this process, I implemented it within the program using Python’s sqlite3, os, pathlib, and shutil modules to access and copy files directly from my iMessage database. The program extracts information such as sender phone number, message date, file type, and timestamp, using this information to create unique filenames for each message. Finally, the script automatically converts .caf audio files into .wav format while accepting .m4a files as-is, then transfers all processed files to a designated folder.
